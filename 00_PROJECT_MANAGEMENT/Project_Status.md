Phase-2 - Research and Topic Exploration

Topic Finalized
Before the Breach: Investigating Machine Learning for Network Intrusion Detection Under Class Imbalance and Data Variability

Problem Statement
Network intrusion detection is challenging because network traffic contains highly imbalanced attack classes and different datasets may represent network behaviour differently. Machine learning models can achieve high overall accuracy while performing poorly on rare attacks or failing to generalize across datasets. This project aims to investigate how class imbalance, data preprocessing, feature representation, and dataset characteristics affect the performance and generalization of machine learning models for netword intrusion detection.

Research Direction
The project will investigate network intrusion detection as a supervised machine learning classification problem, with particular attention to class imbalance, preprocessing, feature representation, and dataset variability.
The final dataset, research question, and experimental design will be determined after systematic dataset investigation and literature review.

Implemetation Requirements
Programming Language: Python
Development Environment: Jupyter Notebook
Minimum Models: 4-5 machine learning classification models
Model comparison will use multple evaluation metrics rather than accuracy alone.
Class-wise performance will be examined, particulary for minority attack classes.
